## Core Architectural Invariants for Coding Agents
- Positioning & Mission Domains: AGBoss (Agent Graph Builder Open Source System) is the TypeScript framework, static compiler (`agboss check`), and production runtime on LangGraph (`npm i agboss`), and HarnessDSL (HDSL) is the declarative graph grammar and verification specification built into AGBoss (analogous to JSX in React or PSL in Prisma) — governing both long-running digital missions (FinTech, SecOps, multi-day enterprise operations) and System-2 Physical AI / robotics mission orchestration above real-time 100-1000 Hz hardware control loops.
- Entry point: `@Application` (`*.application.ts`) is the single assembly root passed to `createApp(App)` and `testWith(App)`. It declares `workflows`, `environment`, `providers`, `budgets`, `piiPolicies`, `observers`, `healthChecks` (`app.checkLiveness()` and `app.checkReadiness()`), `maxConcurrentSteps` (priority queue with `checkReadiness() -> Degraded`), and `compensationTimeout`.
- Flow DSL (`HarnessDSL`, `*.workflow.ts`): Strictly one chained method call per line (`@stylistic/newline-per-chained-call`), including `WorkflowSettings.builder()...build()`. Starts with `start(StartClass)`, chains `.returns(Dto, { about })`, `.toAgent()`, `.toRouter()`, `.toAction()`, `.toWorkflow()`, `.toFinish()`, `.switch(caseOf(Dto, { about }))`, `.chooseOne(route(Target))` with `SpawnPolicy.Always` / `SpawnPolicy.OnDemand`, `.toParallelAgents()`, `.toParallelWorkflows()`, `.join()`, `.joinQuorum({ min, max, deadline })`, `.joinQuorumGroups(...)`, and `.acceptedBy(Arbiter)` / `.acceptedBy(anyOf(A, B))`.
- Transactional Sagas & Compensation: `@Action({ compensateWith: UndoAction, committedBy: CommitAction })` is statically verified by `agboss check` (`[flow.uncompensated-action]`, `[action.invalid-compensator-input]`) and automatically unwound in LIFO order on `app.cancel`, `FailurePolicy.FailFast`, quorum `BranchVerdict.Surplus`, or `BudgetExceededError`.
- Multi-Instance Scaling & Pauses: Distributed `.toParallelWorkflows` / `.toWorkflow` work-stealing via `ExecutionLeaseRepository`, immediate `ExecutionContext.signal` abort (`ExecutionLeaseLostError`) mid-tool-loop on lease loss, and `ChannelHandler.withdraw(withdrawal: ChannelWithdrawal<TRole>)` (`PauseResolution.Withdrawn` / `PauseResolution.Cancelled`) to clean up stale pauses in external UIs.
- Revision Snapshot: `agboss describe --json` exports the full graph topology (`configHash`), per-agent `promptHash`, per-DTO `schemaHash`, and saga links for Langfuse / OpenTelemetry trace coverage correlation and versioned `[ChildWorkflowV1, ChildWorkflowV2]` pause compatibility.
- Naming grammar: Every component name and class ends with its kind suffix (`-application`, `-workflow`, `-workflow-start`, `-workflow-finish`, `-agent`, `-router`, `-action`, `-arbiter`, `-budget`, `-model-provider`, `-pii-policy`, `-channel`), and path DTO classes end with `Dto`.
- Values & DTOs: DTOs are plain objects at runtime (never instantiate with `new` in project code). Durations and money always use unit factories from `agboss/units` (`seconds()`, `minutes()`, `hours()`, `usd()`). Never use `as any` or `as unknown as`.
- Testing (`agboss/testing`): Use `testWith(App, { environment, overrides: [override(Base, Fake)], instances: 2 })` for workflow tests and the 8 isolated unit runners (`testTool`, `testAction`, `testRouter`, `testArbiter`, `testRag`, `testJudge`, `testPii`, `testGuardrail`) for component tests.
