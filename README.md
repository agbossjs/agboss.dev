# agboss.dev

Source for the AGBoss documentation site — [agboss.dev](https://agboss.dev).

**AGBoss** is an open-source application framework for building LangGraph agents in TypeScript ("NestJS for LangGraph agents").

This repository will hold:

- Documentation (getting started, concepts, API reference, guides, CLI)
- Examples (one page per task — the main SEO channel)
- Public roadmap
- About / investor page

Status: repository scaffold only — generator and content not set up yet.
