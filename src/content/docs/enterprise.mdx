<section class="agp-section" id="mesh-hub">
<h2 class="agp-h2">What is the AGBoss Mesh Hub (Enterprise Control Plane)?</h2>
<div class="agp-features">

<div class="agp-feature" id="global-mesh-graph">
<div class="agp-feature-icon">◈</div>
<div>
<h3>Global Agent Mesh Graph</h3>
<p>Interactive fleet map of every <code>@Application</code> service across your organization built from <code>agboss describe --json</code> and signed <code>MeshEnvelope</code> traffic, showing live RPS, p95 latency, <code>pass^k</code> reliability, and USD spend per node.</p>
</div>
</div>

<div class="agp-feature" id="execution-trees">
<div class="agp-feature-icon">⑂</div>
<div>
<h3>Cross-Service Execution Trees</h3>
<p>Unified distributed execution tree keyed by <code>rootExecutionId</code> across <code>Service A → A2A → Service B → MCP → Service C</code>, visualizing human approval pauses, tool retries, budget caps, and LIFO saga rollbacks in one timeline.</p>
</div>
</div>

<div class="agp-feature" id="blast-radius">
<div class="agp-feature-icon">⊕</div>
<div>
<h3>Blast Radius &amp; Federation</h3>
<p>Pre-merge contract impact analysis powered by <code>agboss check --federation</code> that previews every downstream A2A and MCP consumer affected when a <code>@Dto</code> schema or <code>promptHash</code> changes.</p>
</div>
</div>

<div class="agp-feature" id="crystallization-radar">
<div class="agp-feature-icon">⚡</div>
<div>
<h3>Progressive Crystallization Radar</h3>
<p>Automated heatmap flagging <code>DecidedBy.Model</code> steps and low-<code>pass^k</code> tool loops where the LLM is overpaying for deterministic routing or formatting — with one-click PR generation to crystallize them into <code>DecidedBy.Code</code> or <code>@ToolInterceptor</code>.</p>
</div>
</div>

<div class="agp-feature" id="work-stealing">
<div class="agp-feature-icon">⇄</div>
<div>
<h3>Distributed Child Work-Stealing</h3>
<p><code>ChildPlacement.AnyInstance</code> scheduling for horizontal fan-out of <code>.toParallelWorkflows()</code> across a Kubernetes cluster via atomic <code>ClaimPendingChild</code> queue handoffs.</p>
</div>
</div>

</div>
</section>
