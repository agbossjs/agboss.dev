<h2 class="agp-h2">Why AGBoss is a compiler-verified framework, not a hosted platform</h2>
<div class="agp-manifesto">
<p>AGBoss is an open-source TypeScript application framework for LangGraph agents that runs inside your own Node.js infrastructure under the <a href="https://www.apache.org/licenses/LICENSE-2.0" target="_blank" rel="noopener">Apache 2.0</a> license. Instead of routing prompts, checkpoints, and traces through a third-party SaaS platform, AGBoss compiles your workflows, dependency injection container, and FinOps budgets directly into your service.</p>
<p>As multi-agent systems grow to hundreds of nodes and AI coding agents generate the implementation, teams need deterministic compiler guardrails — not another cloud dashboard. AGBoss enforces <a href="/concepts/architecture/">7 distributed-systems invariants</a> at build time so coding agents and engineers ship reliable systems inside your existing perimeter.</p>
</div>
</section>

<p class="agp-phase-label">Next</p>
<h3>Sandboxes, Time-Travel Replay, Event Ingress &amp; Physical AI Bridges</h3>
<p class="agp-phase-goal">Ephemeral microVM tool isolation, mid-graph checkpoint forking, automated SFT/DPO distillation, broker backpressure, and robotics/IoT protocols.</p>
<ul class="agp-phase-items"><li><strong>Isolated Code &amp; Browser Sandboxes (<code>@agboss/sandbox</code> — Firecracker, Docker, E2B, Playwright)</strong><span>Run untrusted LLM-generated code, shell commands, and Computer-Use browser actions inside ephemeral microVMs with strict network egress allowlists and automatic filesystem snapshot rollback on saga <code>compensateWith</code>.</span></li>
<li><strong>Time-Travel Debugger &amp; Mid-Graph Forking (<code>agboss replay --from-step &lt;node&gt;</code>)</strong><span>Fork any historical production <code>ExecutionRecord</code> from an arbitrary node in the graph — replaying upstream steps at <code>$0</code> from the checkpoint while testing a new prompt, model, or tool fix on the downstream branches.</span></li>
<li><strong>Crystallization Distillation &amp; Fine-Tuning Exporter (<code>agboss distill</code>)</strong><span>One-command export of verified <code>JudgeVerdict.passed()</code> trajectories and human-labeled <code>eval ui</code> runs (with <code>@PiiPolicy</code> tokens masked) into SFT / DPO JSONL datasets to distill expensive frontier <code>@Agent</code> and <code>@Router</code> nodes into compact in-house models or <code>DecidedBy.Code</code> handlers.</span></li>
<li><strong>Event-bus &amp; streaming ingress (<code>@agboss/kafka</code>, <code>@agboss/nats</code>, <code>@agboss/rabbitmq</code>, <code>@agboss/sqs</code>, <code>@agboss/pubsub</code>)</strong><span>Consumer/producer adapters wired directly to <code>maxConcurrentSteps</code> backpressure (pausing partitions when pod slots saturate), <code>MeshEnvelope</code> (<code>agboss-mesh</code>) header propagation, and idempotent deduplication.</span></li>
<li><strong>Turnkey Human-in-the-Loop <code>@Channel</code> packages (<code>@agboss/slack</code>, <code>@agboss/teams</code>, <code>@agboss/telegram</code>, <code>@agboss/github</code>, <code>@agboss/linear</code>, <code>@agboss/pagerduty</code>)</strong><span>Signed webhook verification, interactive approval modals for two-phase <code>app.resume(&#123; pauseId, reply &#125;)</code>, and automatic message withdrawal (<code>ChannelHandler.withdraw</code>) when a parallel quorum branch becomes <code>BranchVerdict.Surplus</code>.</span></li>
<li><strong>Envelope PII Encryption &amp; Cryptographic Erasure (<code>@agboss/kms</code>)</strong><span>AWS KMS, GCP KMS, Azure KeyVault, and HashiCorp Vault providers encrypting <code>PiiTokensRepository</code> with per-tenant DEKs — enabling instant GDPR Right-to-be-Forgotten compliance by rotating or destroying a tenant key without rewriting historical traces.</span></li>
<li><strong>Physical AI, Robotics &amp; Industrial IoT Bridges (<code>@agboss/ros2</code>, <code>@agboss/mqtt</code>, <code>@agboss/opcua</code>)</strong><span>Low-latency telemetry ingestion and hardware safety-interlock bridges connecting System-2 HDSL mission planners to physical robot fleets, drones, and warehouse automation.</span></li>
<li><strong>Federation contract registry &amp; CI gates</strong><span>Automated snapshot publishing and pull-request blast-radius checks for <code>agboss check --federation</code> across multi-repo organizations.</span></li></ul>
