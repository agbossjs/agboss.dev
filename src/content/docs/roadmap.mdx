<h2 class="agp-h2">Why AGBoss is a framework, not a hosted platform</h2>
<div class="agp-manifesto">
<p>AGBoss is an open-source TypeScript application framework for LangGraph agents that runs inside your own Node.js infrastructure under the <a href="https://www.apache.org/licenses/LICENSE-2.0" target="_blank" rel="noopener">Apache 2.0</a> license. Instead of routing prompts, checkpoints, and traces through a third-party SaaS platform, AGBoss compiles your workflows, dependency injection container, and FinOps budgets directly into your service.</p>
<p>When prompts and customer records sit on someone else's servers, security teams, compliance officers, and regulators ask hard questions: where is the data, who can see it, and can it leave the perimeter?</p>
<p>AGBoss takes the path Spring took for Java and NestJS took for Node.js: a <strong>strict application framework</strong> built specifically for multi-agent systems. You declare components in TypeScript; the framework wires, validates, tests, and traces them inside your perimeter.</p>
</div>
</section>
