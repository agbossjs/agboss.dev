## Shipped

- Core decorator components (`@Agent`, `@Tool`, `@Router`, `@Workflow`)
- Constructor injection
- Build-time workflow checks

## In progress

- Component-level regression testing (Trace → Case → Suite → Version → Compare → Promote)

## Planned

- Saga & cancellation for long-running workflows
- Composition between workflows
- MCP / A2A / OpenAPI adapters

Not available yet — tracked here so the intent is visible before it ships.

- Automated dependency and framework upgrades
- Governance & compliance tooling (audit trails, policy checks)
