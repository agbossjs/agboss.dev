---

AGBoss — short for **A**gent **G**raph **B**uilder, **O**pen-**S**ource **S**oftware — is an application framework for building [LangGraph](https://www.langchain.com/langgraph) agents in TypeScript — think of it as NestJS for LangGraph agents.

Agents, tools and routers are declared as decorator components and wired together through constructor injection, inside a single workflow file. AGBoss embeds into an existing Node.js backend: bring your own backend, no ecosystem lock-in.

Continue to [Installation](/getting-started/installation/).
