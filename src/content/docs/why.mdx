<div class="agp not-content">

<p class="agp-lead">AGBoss makes building LangGraph agents in TypeScript faster, easier to read and safer to change. You declare what each component is; the framework wires them into a graph and gives every run tests, traces and a price tag.</p>

<div class="agp-features">

<div class="agp-feature">
<div class="agp-feature-icon">@</div>
<div>
<h3>AGBoss is declarative</h3>
<p>Agents, tools, routers and workflows are classes with a decorator. Dependencies arrive through the constructor, the workflow wires them into a graph.</p>
<p>The code reads like the diagram you would have drawn, so it's quick to write and quick to review.</p>
</div>
</div>

<div class="agp-feature">
<div class="agp-feature-icon">✓</div>
<div>
<h3>AGBoss is testable</h3>
<p>Every component can be unit-tested with the model and tools stubbed out. Configurations can be compared side by side, so a prompt change is an A/B test, not a guess.</p>
</div>
</div>

<div class="agp-feature">
<div class="agp-feature-icon">⌁</div>
<div>
<h3>AGBoss is observable</h3>
<p>Each run is traced end to end, and the trace link sits right under the answer. You see which agent ran, what it called and why it routed where it did.</p>
</div>
</div>

<div class="agp-feature">
<div class="agp-feature-icon">$</div>
<div>
<h3>AGBoss is cost-aware</h3>
<p>Token spend is part of the result of every turn. Budgets are reserved before a run starts, so one runaway conversation can't drain the account.</p>
</div>
</div>

<div class="agp-feature">
<div class="agp-feature-icon">↔</div>
<div>
<h3>AGBoss is lock-in free</h3>
<p>It embeds into the Node.js backend you already have. Bring your own HTTP server, database and model provider; nothing has to move to a new platform.</p>
</div>
</div>

<div class="agp-feature">
<div class="agp-feature-icon">◇</div>
<div>
<h3>AGBoss is LangGraph</h3>
<p>Under the decorators it's a regular LangGraph graph. Everything LangGraph can run, AGBoss can run; it just takes the wiring off your hands.</p>
</div>
</div>

</div>
