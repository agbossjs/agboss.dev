<div class="agp not-content">

<p class="agp-lead">Modern engineering teams already know two truths: complex problems require networks of specialized agents, and engineers no longer write orchestration boilerplate by hand — <strong>AI coding agents (Codex, Cursor, Windsurf, Copilot, Gemini CLI, Claude Code)</strong> write the code under an engineer's architectural direction. <strong>AGBoss</strong> (<em>Agent Graph Builder Open Source System</em>) is the TypeScript framework, static graph compiler (<code>agboss check</code>), and production runtime on LangGraph (<code>npm i agboss</code>), and <strong>HarnessDSL (HDSL)</strong> is the declarative graph grammar and verification specification built into AGBoss — giving coding agents hard distributed-systems guardrails so graphs with hundreds of nodes stay deterministic, cache-invariant, and refactorable.</p>

<div class="agp-features">

<div class="agp-feature">
<div class="agp-feature-icon">1</div>
<div>
<h3>Computational Role Segregation & Canonical Topology</h3>
<p>In raw graph SDKs, coding agents create "god nodes" and format the same topology ten different ways. AGBoss segregates <code>@Agent</code>, <code>@Router</code>, <code>@Arbiter</code>, and <code>@Action</code>, and enforces a <strong>1-to-1 isomorphism</strong> between graph topology and code layout (<code>in-degree = 1</code> inline, <code>in-degree &ge; 2</code> top-level entry, 1 chained call per line).</p>
</div>
</div>

<div class="agp-feature">
<div class="agp-feature-icon">2</div>
<div>
<h3>Path-Scoped SSA Dataflow & Provenance</h3>
<p>Shared mutable state bags (<code>Annotation.Root</code>) collapse at 50+ nodes when coding agents hallucinate nullable fields or consume stale loop state. <code>agboss check</code> runs static Path-Scope dominance analysis and emits <code>.agboss/types.d.ts</code> with narrowed <code>Produced&lt;Dto, Producer&gt;</code> inputs, rejecting missing (<code>[input.missing-on-path]</code>) or stale (<code>[input.outdated-on-path]</code>) values before runtime.</p>
</div>
</div>

<div class="agp-feature">
<div class="agp-feature-icon">3</div>
<div>
<h3>Prompt Prefix Cache Invariance & Boundary PII</h3>
<p>Interpolating dynamic inputs into system prompts or masking PII with random UUIDs destroys LLM KV-cache hit rates (up to 10x higher token cost). AGBoss enforces <code>[prompt.input-in-instructions]</code> at compile time and uses deterministic HMAC pseudonymization (<code>PiiAction.replaceWithToken()</code>) so identical values produce identical tokens across turns while restoring real values inside <code>@Tool</code> calls.</p>
</div>
</div>

<div class="agp-feature">
<div class="agp-feature-icon">4</div>
<div>
<h3>Transactional LIFO Sagas & Idempotent Execution</h3>
<p>When a parallel branch fails, a quorum cancels slow siblings as <code>Surplus</code>, or a budget trips, external side effects cannot be left dangling. Side-effecting <code>@Action</code> nodes declare <code>compensateWith</code> and <code>committedBy</code> (verified by <code>[flow.uncompensated-action]</code>) and receive a deterministic <code>step.idempotencyKey</code> for safe retry and LIFO rollback.</p>
</div>
</div>

<div class="agp-feature">
<div class="agp-feature-icon">5</div>
<div>
<h3>Zero-Leakage DI & 4-Stage Infrastructure Scaling</h3>
<p>Every component is wired inside a single <code>@Application</code> root using class-inheritance DI (<code>override(Base, Fake)</code>) and deterministic lifecycle hooks (<code>OnInit &rarr; OnStart &rarr; OnStop &rarr; OnDestroy</code>). Scale from zero-setup <code>InMemory*</code> stores in tests to <code>Sqlite*</code> WAL single-node durability and multi-pod 30s lease handoff without changing a single line of business logic.</p>
</div>
</div>

<div class="agp-feature">
<div class="agp-feature-icon">6</div>
<div>
<h3>Progressive Crystallization & Universal Coding Skills</h3>
<p>Start with flexible <code>DecidedBy.Model</code> routers and multi-tool agents, then join <code>agboss describe --json</code> (<code>configHash</code>, <code>promptHash</code>, <code>schemaHash</code>) with production traces to crystallize settled paths into zero-cost <code>DecidedBy.Code</code> routers and <code>@Action</code> nodes — guided by <code>AGENTS.md</code> and 12 offline-synced skill modules.</p>
</div>
</div>
