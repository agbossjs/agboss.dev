<div class="agboss-lede">
	<p class="agboss-slogan">Your coding agent writes the graph. AGBoss proves it right.</p>
	<p><strong>AGBoss</strong> (<em>Agent Graph Builder Open Source System</em>) is the framework, static compiler (<code>agboss check</code>), and runtime on LangGraph, and <strong>HarnessDSL (HDSL)</strong> is its built-in declarative graph grammar — enforcing 7 distributed-systems invariants with offline-synced <code>AGENTS.md</code> coding skills. <a href="https://www.apache.org/licenses/LICENSE-2.0" target="_blank" rel="noopener">Apache 2.0</a>.</p>
	<p class="agboss-sr-only">AGBoss (Agent Graph Builder Open Source System) is an open-source TypeScript framework, static graph compiler (<code>agboss check</code>), and production runtime layered on top of LangGraph (<code>npm i agboss</code>). Inside AGBoss, HarnessDSL (HDSL) is the declarative graph grammar and verification specification (just as JSX is to React or PSL is to Prisma) that defines how <code>*.workflow.ts</code> <code>flow</code> chains and contract decorators express narrow <code>@Dto</code> handoffs, Path Scope, <code>in-degree = 1</code> vs <code>in-degree &gt;= 2</code> canonical topology, <code>&#123; about &#125;</code> staleness tracking, quorums, and <code>compensateWith</code> / <code>committedBy</code> sagas. When AI coding agents decompose a complex problem into hundreds of nodes on raw orchestration libraries, they create a mutable God State Object with dozens of optional fields, mix LLM reasoning with non-idempotent side effects, break provider KV prefix caches, and lose rollback invariants. AGBoss embeds 7 classical distributed-systems patterns directly into its HarnessDSL grammar, static compiler (<code>agboss check</code> + <code>.agboss/types.d.ts</code>), and auto-synced <code>AGENTS.md</code> + 12 skill reference modules.</p>

## Why engineering teams build production agents on AGBoss

<p>Unlike lightweight prompt wrappers or hosted agent platforms that lock your state and traces behind a proprietary API, AGBoss compiles directly into your Node.js service with verifiable runtime guarantees.</p>

<ul>
	<li><strong>100% compile-time graph, Path Scope, and saga verification:</strong> Every path slot, constructor dependency, DTO schema, and <code>compensateWith</code> rollback path (<code>[flow.uncompensated-action]</code>) is verified by the <a href="https://www.typescriptlang.org/" target="_blank" rel="noopener">TypeScript</a> compiler and <code>agboss check</code> before deployment.</li>
	<li><strong>200+ decision and chat model endpoints:</strong> Built on <a href="https://www.langchain.com/langgraph" target="_blank" rel="noopener">LangGraph</a> and OpenRouter with calibrated decision routing, tenant-weighted rate limiting at 120 calls per minute, and shared 429 cooldowns.</li>
	<li><strong>100% self-hosted trace and PII isolation:</strong> Sensitive fields are pseudonymized before leaving your boundary, and full execution trees export to self-hosted <a href="https://langfuse.com/" target="_blank" rel="noopener">Langfuse</a> and OpenTelemetry collectors alongside <code>agboss describe --json</code> revision snapshots.</li>
</ul>
