## What is AGBoss and why is it built on LangGraph?

**AGBoss** is an open-source, Spring-style TypeScript framework for building multi-agent applications on top of [LangGraph](https://www.langchain.com/langgraph). LangGraph provides the durable state-graph execution runtime and checkpointing substrate; AGBoss adds a declarative component architecture (`@Application`, `@Workflow`, `@Agent`, `@Router`, `@Arbiter`, `@Action`, `@Tool`), constructor dependency injection (`@Injectable`), explicit `@Dto` data contracts, and a static workflow compiler (`agboss check`).

- **Why dependency injection matters:** Components remain stateless and single-responsibility, so you can swap real external services, SQLite repositories, and test mocks at the `@Application` boundary without rewriting workflow logic.
- **Why static validation matters:** `npx agboss check` analyzes every workflow route before runtime—catching missing upstream DTO inputs, stale data after revision loops, and uncompensated side effects that pass standard TypeScript (`tsc`) checks in raw shared-state graphs.
- **Why deterministic testing matters:** With `testWith()`, dedicated unit runners (`testAgent`, `testRouter`, `testTool`, `testAction`), VCR cassettes, and `VirtualClock`, you can test individual components and full multi-agent workflows offline in milliseconds without live LLM calls.

## How does AGBoss catch workflow dataflow errors before runtime?

In raw graph orchestrators that share a single mutable state object (`Annotation.Root`), a router branch that skips an upstream producer compiles cleanly under `tsc` and fails only in production when that branch is taken. AGBoss verifies **Path Scope** across every possible execution path at build time via `agboss check` and generated `.agboss/types.d.ts` provenance types (`Produced<Dto, Producer>`):

```ts no-check: intentional [input.missing-on-path] example from 02-path-scope-proof
// fast-track-contract.workflow.ts
@Workflow({
  name: "fast-track-contract-workflow",
  version: "1.0.0",
  flow: [
    start(FastTrackContractWorkflowStart)
      .returns(ContractDraftDto)
      .toRouter(ContractTrackRouter)
      .chooseOne(
        // Standard path produces ComplianceApprovalDto before publishing
        route("standard")
          .toAgent(ComplianceCheckAgent)
          .returns(ComplianceApprovalDto)
          .to(PublishContractAction),
        // Fast-track skips ComplianceCheckAgent and jumps straight to PublishContractAction!
        route("fast-track")
          .to(PublishContractAction),
      ),
    path(PublishContractAction)
      .returns(PublishedContractDto)
      .toFinish(FastTrackContractWorkflowFinish),
  ],
})
export class FastTrackContractWorkflow {}
```

Running `npx agboss check` rejects this graph before a single model call or side effect executes:

```text
error [input.missing-on-path]: publish-contract-action requires ComplianceApprovalDto
  (parameter 'approval'), which is not produced on path:
  fast-track-contract-workflow-start → contract-track-router → publish-contract-action
  (produced only on: fast-track-contract-workflow-start → contract-track-router → compliance-check-agent → publish-contract-action)
```
