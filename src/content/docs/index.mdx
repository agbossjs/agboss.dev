	<p>100% open source under <a href="https://www.apache.org/licenses/LICENSE-2.0" target="_blank" rel="noopener">Apache 2.0</a>. Your agents, your infrastructure, your rules.</p>
	<p class="agboss-sr-only">AGBoss is an open-source TypeScript application framework layered on top of LangGraph for deterministic orchestration of multi-agent systems and autonomous missions. Components declare typed DTOs, constructor dependencies, and transactional compensation contracts inside an <code>@Application</code> container, while <code>agboss check</code> statically verifies every graph path, review loop, and saga rollback before any model runs.</p>

## Orchestrating Long-Running Digital & Physical Missions (System-2 Planner)

<div class="agboss-missions">
	<div class="agboss-mission-card">
		<span class="agboss-mission-kicker">DOMAIN 01 · ENTERPRISE BACKEND, FINTECH &amp; SECOPS</span>
		<h3>Long-Running Digital Autonomous Missions</h3>
		<p>Orchestrate multi-step workflows that run for minutes or days, fan out into distributed child workflows stolen by idle Kubernetes pods via <code>ExecutionLeaseRepository</code>, wait for human sign-off in Slack with automatic <code>ChannelHandler.withdraw</code> of stale buttons, and unwind external side effects in LIFO order via <code>compensateWith</code> and <code>committedBy</code> when cancelled or aborted.</p>
	</div>
	<div class="agboss-mission-card">
		<span class="agboss-mission-kicker">DOMAIN 02 · PHYSICAL AI, ROBOTICS &amp; SMART DEVICES</span>
		<h3>High-Level System-2 Mission Planner</h3>
		<p>In a dual-loop architecture, low-level hardware controllers and safety reflexes run at 100–1000 Hz while AGBoss acts as the System-2 &ldquo;cerebral cortex&rdquo;: gathering multimodal model quorums via <code>.joinQuorum()</code> and <code>@Arbiter</code>, pausing missions safely via <code>@ChannelRole</code> with telemetry for human operators, validating coordinates via DTOs and <code>agboss check</code>, and triggering LIFO compensating actions to return actuators to a safe hold state on abort.</p>
	</div>

## Why engineering teams build production agents on AGBoss

<p>Unlike lightweight prompt wrappers or hosted agent platforms that lock your state and traces behind a proprietary API, AGBoss compiles directly into your Node.js service with verifiable runtime guarantees.</p>

<ul>
	<li><strong>100% compile-time graph, Path Scope, and saga verification:</strong> Every path slot, constructor dependency, DTO schema, and <code>compensateWith</code> rollback path (<code>[flow.uncompensated-action]</code>) is verified by the <a href="https://www.typescriptlang.org/" target="_blank" rel="noopener">TypeScript</a> compiler and <code>agboss check</code> before deployment.</li>
	<li><strong>200+ decision and chat model endpoints:</strong> Built on <a href="https://www.langchain.com/langgraph" target="_blank" rel="noopener">LangGraph</a> and OpenRouter with calibrated decision routing, tenant-weighted rate limiting at 120 calls per minute, and shared 429 cooldowns.</li>
	<li><strong>100% self-hosted trace and PII isolation:</strong> Sensitive fields are pseudonymized before leaving your boundary, and full execution trees export to self-hosted <a href="https://langfuse.com/" target="_blank" rel="noopener">Langfuse</a> and OpenTelemetry collectors alongside <code>agboss describe --json</code> revision snapshots.</li>
</ul>
