title: CLI
description: The agb command-line tool.
---

The `agb` CLI (short alias for `agboss`, chosen over `ag` to avoid clashing with The Silver Searcher) scaffolds and generates AGBoss code.

## `agb init`

Scaffolds a new AGBoss project.

## `agb generate`

Generates a new component (agent, tool, router) into the current workflow.
