# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| `0.1.0` (latest) | Yes |
| `< 0.1.0` | No |

## Reporting a Vulnerability

Please **do not** report security vulnerabilities through public GitHub issues.

Instead, report vulnerabilities privately via [GitHub Security Advisories](https://github.com/agbossjs/agboss/security/advisories/new) on the main framework repository. Include reproduction steps, affected component or documentation page, and potential impact. We will acknowledge receipt within 48 hours.
